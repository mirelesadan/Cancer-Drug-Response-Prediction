# External drug-response data: feasibility audit

**Status (24 September 2026):** Documentation review only. No external dataset was downloaded, joined, or scored. A direct external RMSE for the frozen GDSC2 models is **not yet defensible**.

## Candidate sources

| Source | Verified contents and terms | Compatibility issue |
| --- | --- | --- |
| [PRISM Repurposing 19Q4 v4](https://figshare.com/articles/dataset/PRISM_Repurposing_19Q3_Primary_Screen/9393293) | Broad's archived secondary screen reports 1,448 compounds across 489 cell lines, with eight fourfold doses starting at 10 µM. The figshare record states **CC BY 4.0**. [Broad's processing code](https://github.com/broadinstitute/repurposing/blob/master/secondary_processing_script.R) computes an AUC and a fitted `log2.ic50`; the latter is undefined when the fitted curve cannot cross 50% within the tested dose interval. [DepMap 19Q4 Public v3](https://figshare.com/articles/dataset/DepMap_19Q4_Public/11384241) supplies an archival RNA-seq release and is also labeled **CC BY 4.0**. | PRISM's AUC is a different endpoint. Its fitted IC50 uses log base 2 of the recorded dose, whereas the TDC GDSC2 `Y` scale has no verified concentration reference for this snapshot. PRISM cell and compound identifiers require explicit crosswalks. |
| [CTRP CTD² v2.0](https://forum.depmap.org/t/depmap-portal-datasets/3695) | DepMap identifies the imported December 2015 CTD² data as viability measurements covering 907 cell lines and 545 chemical perturbations. The portal labels its summary endpoint [log2 AUC](https://depmap.org/portal/data_explorer_2/?xDataset=CTRP_log2AUC_collapsed&xFeature=BIRINAPANT&yDataset=expression&yFeature=CASP12). DepMap describes the [raw experiment-ID → cell-ID mapping](https://forum.depmap.org/t/extracting-auc-data-for-drug-cell-line-combinations-from-ctrp-ctd-2-dataset/3128). | AUC is not IC50. Raw experiment, cell, and compound IDs must be joined and audited; compound structures and file-specific use terms must be checked in the selected archive before use. DepMap warns that [hosted collaborator datasets may have different licenses](https://forum.depmap.org/t/license-for-data-found-in-the-depmap-portal/130). |

PRISM is the more promising **first audit target** because its secondary screen has a fitted IC50 endpoint and an archived, versioned response release. The [Broad Repurposing Hub](https://repo-hub.broadinstitute.org/repurposing) offers sample-level Broad IDs, SMILES, and InChIKeys, including archived annotation versions. Its page describes metadata as CC BY 4.0 while also stating research-use and commercial-repackaging conditions; those terms should be reviewed separately from the PRISM and DepMap figshare terms. Broad has [acknowledged incomplete treatment-metadata matching for a later PRISM release](https://forum.depmap.org/t/request-about-treatment-metadata-for-prism-repurposing-public-24q2-release/4474), so a drug-name match alone is inadequate.

## Why the present models cannot be assigned an external RMSE

The frozen study predicts TDC's provided `Y`, which TDC calls log-normalized IC50. The [GDSC2 audit](data_audit.md#target-meaning-and-limits-of-verification) records that the exact TDC snapshot-to-Sanger mapping and concentration reference remain unresolved. Converting PRISM's fitted `log2.ic50` to natural-log concentration would change log base, but would **not** by itself establish that its numeric values equal TDC `Y`. CTRP's AUC has no such direct conversion. Comparing either endpoint to predictions with RMSE would mix assay and scale differences.

The model's PCA expects **17,737 ordered TDC expression positions**, including 317 repeated gene symbols. DepMap expression is a separate RNA-seq product; Broad documents its 19Q4 CCLE matrix as [log2(TPM+1)](https://github.com/broadinstitute/Celligner_ms). The TDC feature-generation and normalization steps have not been mapped to that matrix. Mapping by symbol alone could conflate repeated positions or silently alter model inputs. Cell-line names in TDC also lack source model IDs, and PRISM compound sample IDs need a structure-level match to the TDC SMILES. These are verified properties of the present audit plus **inferred transfer blockers**; actual overlap and ambiguity rates remain unmeasured.

## Metadata-only audit and decision gate

1. Pin the exact PRISM, DepMap expression, and Repurposing Hub annotation versions; record file-level terms, URLs, retrieval dates, and checksums. Obtain only the metadata and schema needed for an overlap audit first.
2. Build one-to-one cell crosswalks from TDC names to DepMap model IDs and stable external identifiers (for example Sanger IDs or Cellosaurus RRIDs), logging every ambiguous or unmatched line. Match compounds by curated ID and standardized structure/InChIKey, retaining salt and stereochemistry conflicts as exclusions.
3. Count eligible **known-drug, training-unseen cell-line** pairs before inspecting external responses. Separate a set using the already held-out GDSC2 test lines from any genuinely new external cell lines.
4. Verify response definitions from the selected release's files and processing code: concentration units, log base/reference, curve-fit censoring, direction, duplicate experiments, and assay-specific normalization. Independently audit expression feature IDs, order, duplicate symbols, and scale against the frozen PCA input.

**Gate:** Only claim direct external RMSE if each scored pair has an unambiguous drug/cell mapping, the frozen expression transform can be applied without an unsupported feature conversion, and the external target is demonstrated to be on the same numerical scale as TDC `Y`. Otherwise, a prespecified within-drug rank concordance on mapped, training-unseen lines could be reported as an **exploratory cross-assay check**, with per-drug counts and undefined correlations explicit. It would not be evidence of numeric IC50 calibration or patient effectiveness.
