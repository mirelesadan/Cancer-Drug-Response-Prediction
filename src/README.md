`retrieve_gdsc2.py`, `audit_gdsc2.py`, and `prepare_gdsc2.py` handle data access and preparation. `run_baselines.py` and `run_neural.py` fit the primary models; `run_sensitivity.py` and `evaluate_final.py` implement the locked sensitivity and test analyses. Matching `check_*.py` scripts verify saved artifacts and replay predictions. See the root README and reports for the execution order and frozen-run boundary.

For the optional molecular GNN, `gnn.py` defines the graph representation and model, `run_gnn.py` performs the fixed three-seed validation run, `evaluate_gnn.py` compares the retained checkpoints on the same original test pairs, and `check_gnn.py` and `check_gnn_final.py` independently replay the saved predictions and metrics. See the [GNN extension report](../results/gnn_final.md) for the required environment and locked-artifact boundary.
